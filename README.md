# Homebrew Tap for printcursive-cli (printcursive.com)

Official Homebrew tap for **[printcursive.com](https://printcursive.com)** command-line tools.

## Installation

```bash
brew tap AbigailDavised/printcursive
brew install printcursive-cli
```

## Quick Test

```bash
printcursive-cli --help
```

# PrintCursive — Continuous Cursive Handwriting Worksheet Generator Engine

Employs true cubic Bezier continuous ligature curves adhering to the D'Nealian 29-degree slant angle geometry and strict 3:4:3 x-height guideline ratios for K-5 penmanship instruction.
